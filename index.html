How it works

Four steps, and none of them are data entry.

  1. Log in with Discord

    StaffDesk shows the servers you manage. Pick the one you want a workspace for.

  2. Invite the bot

    If StaffDesk is not in that server yet, you will get an Invite StaffDesk button. Approve it once and come straight back.

  3. Run /setup

    The bot reads every role and every member, then proposes which roles are staff and why — from role names, Discord permissions and where each role sits in the hierarchy.

  4. Confirm, and you are done

    Correct anything the detection got wrong. Profiles are created for everyone holding a staff role, and the dashboard fills in immediately.

FAQ

Questions worth asking first.

What if StaffDesk detects the wrong roles?

Every proposed role is shown with the reason it was picked and how confident the detection is, so you can see what it was reasoning from. Change anything before you confirm. Roles you set by hand are marked as manual and later syncs leave them alone.

What if none of our roles have obvious names?

Names are only the first signal. StaffDesk also reads Discord permissions — a role that can ban or time out members is a staff role whatever it is called — and role hierarchy position. If all three come back empty, you configure the roles yourself and nothing is guessed.

What permissions does the bot ask for?

The invite link requests Administrator, which keeps setup to a single click and avoids per-channel permission problems later. StaffDesk does not actually need it — it reads roles and members through Discord's gateway intents, and otherwise only posts messages. If you would rather grant the minimum, set BOT_PERMISSIONS to 84992 in bot.py and re-invite.

Do warnings show up in Discord?

The warned member gets a direct message with the reason. If they have DMs from server members turned off, the warning is still recorded and the dashboard shows that it was not delivered, so you know to follow up another way.

What happens when someone leaves the server?

Their profile is archived, not deleted. Warnings, tasks and audit entries stay readable, and if they rejoin, the same profile picks back up.

Can more than one person manage the workspace?

Yes. The server owner has access by default and can grant it to any Discord role — so your admin team signs in with the roles they already have.
